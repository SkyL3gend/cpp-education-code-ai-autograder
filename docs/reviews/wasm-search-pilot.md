## 共用框架与本题规则

执行与校准继续由共享任务 profile 驱动，普通 Web 只提供 LLM 适配测评。白名单限定 T1 手机号、T2 生日提醒、T3 日期校验、T4 姓名检索的明确 `1.0.0` 版本，未知任务或版本仍拒绝。本轮不增加外部部署依赖、不更换 SDK，也不增加学生宿主 EXE 回退。

本题要求真实调用上传程序的 `ContactBook::searchByName`，按任意位置子串匹配，忽略 **ASCII** 字母大小写，返回全部匹配记录；空关键字返回空列表。`matches` 是完整联系人记录，必须保留原 ID、姓名、电话和生日，不以姓名列表代替。`contacts_after` 应与原通讯录一致，检索过程不能将姓名原地小写、删除记录或重新编号。

样例目录为 `examples/wasm_search/`。本题变体覆盖的是 `contactbook.cpp`，其他文件包括 `validators.cpp` 均来自基础工程；不能误用前三题的 validators 覆盖方式。合并顺序为 `validators.h → contactbook.h → validators.cpp → contactbook.cpp`，仅去掉本地头文件包含和 `#pragma once`，没有 `main()`。正确版本新增的 `<cctype>` 保留。四模块 ZIP 已逐字节比对来源、检查 CRC 与安全路径，不含 Key、上传记录或二进制依赖。

## 五项正式用例与实际差异

| 用例 | 输入关键字 | 正确版预期 | 缺陷版预期 |
| --- | --- | --- | --- |
| `c_case_insensitive` | `an` | 返回 `Anna Liu`（ID 1）与 `annabel`（ID 2） | 仅 `annabel`，`a_matches` 不符 |
| `c_chinese` | `王` | 返回 `王强`（ID 3） | 符合 |

| `c_empty_keyword` | 空串 | 返回空匹配 | 符合 |
| `c_no_match` | `zzz` | 返回空匹配 | 符合 |

实际运行与规则推导一致：正确版 **5 MATCH**，缺陷版 **3 MATCH、2 MISMATCH**；两版全部五项的 `a_contacts` 均符合。`matches` 与 `contacts_after` 按完整记录多重集比较，不依赖顺序，但同名联系人、重复记录次数和原 ID 不能丢失。
