## 3. 编译与执行隔离

新增 `wasm_pilot` 链路：WASI SDK 将 C++ 编译为 WASIp1，Binaryen 转换异常指令，Wasmtime 实际执行 WASM。学生程序没有宿主 EXE 回退；worker 只连接标准输入输出，不预开放宿主目录、环境变量、网络 socket 或额外宿主函数。

首版原生编译器尚未隔离；本轮后续实现将 clang 前端、链接器和 Binaryen 全部放入零能力 Windows LPAC/AppContainer，隔离不可用即拒绝编译。策略标识为 `wasi-p1-stdio-appcontainer-compiler-v3`，其中 v3 是策略迭代标识，不是新发布的软件版本号。

- 编译输入复制到独立目录，只读授权源码和 SDK，仅专用输出目录可写；不向用户目录或项目祖先目录授予编译器权限。
- 宿主解析受限工具计划并逐项启动，允许工具清单固定，每个原生工具继续使用隔离令牌；只继承三路标准句柄。
- 编译与运行使用 Job Object、墙钟、CPU/燃料、内存、进程树、合计输出及工作目录预算。日志按上限读取，可写目录整体监测，不跟随 reparse/junction；磁盘用量是轮询限制，尚非硬配额。
- 正常退出撤销临时权限、DOS 盘符映射及 AppContainer profile。强杀后的宿主 journal 位于 guest 不可访问的位置；恢复时核对用户、SDK、派生 SID、固定目录、PID 与创建时间，只清理已死亡宿主的精确匹配资源，不递归删除历史临时目录。

真实探针结果：宿主私有文件读取、源码写入与网络连接被拒绝，指定输出目录写入成功。实现见 [WASM 后端](../src/cpp_assessor/sandbox/wasm.py)、[输入暂存](../src/cpp_assessor/sandbox/wasm_staging.py)、[AppContainer 编译器](../src/cpp_assessor/sandbox/appcontainer.py)、[Windows 资源监测](../src/cpp_assessor/sandbox/win32.py)。这些本机试验支持当前边界，不等于生产安全认证。

## 4. 判断程序校准与学生补充检查

本轮增加两种用途不同的检查，均不改变题库原有四项正式计数：

1. **判断程序回归校准**：在支持的固定手机号工程上，用同一套生成驱动、观测器和迁移关系执行独立正确/已知缺陷夹具，共 14 次；同时验证原联系人状态得到保留。记录绑定任务、源码快照、bundle、夹具和环境，变更后不能沿用旧记录。它是有限范围回归，等级继续保持 `CHECKED`，不能自动授予 `CALIBRATED`、`REVIEWED` 或评分资格。
2. **学生程序补充检查**：对当前学生 WASM 另外执行错误首位、空号码、全角数字三项。证据绑定冻结的运行、任务、bundle、环境及 WASM 字节哈希；网页独立展示，无法比较时不认定业务缺陷。

实现：[目标回归与补充检查](../src/cpp_assessor/planning/target_calibration.py)。当前范围和限制见[回归校准说明](reviews/2026-10-22-T1判断程序回归校准.md)。

以下三次使用先前真实模型保存的判断程序，在新版隔离中重新编译执行，没有新模型请求，也没有沿用旧观测：

## 5. 便携包与性能

便携包包含 Python、Web 依赖、Wasmtime、裁剪后的 WASI SDK 与 Binaryen。当前机器独立解压测试中，清除 Python/编译器/项目相关环境变量，PATH 只保留 System32，仍可启动、编译并测评；使用者不必另装 Python、编译器、Docker、WSL 或虚拟机。模型仍需要使用者自己的 Key、可用账户及网络；源码 `git clone` 本身不包含这些二进制依赖。

| 采样对象 | 本轮测量 | 解释 |
| --- | --- | --- |
| v3 完整隔离编译 | 19.189、19.204、19.584 秒；中位数 **19.204 秒** | 含输入暂存、AppContainer、封闭 VFS 与异常转换；无模型请求 |
| 新 worker 启动/JIT/执行 | 10 次 610–666 ms；中位数 **623 ms** | 每次均重新启动 worker；不是已预热执行时间 |
| 示例 WASM | 2,758,094 字节 | 含 C++ 标准库和完整驱动 |
| 独立包 Web 就绪 | 一次独立回放采样 1.122 秒；最终包复核 1.219 秒 | 测量 HTTP 就绪，不是完整测评耗时 |
| 独立包新在线测评 | **93.89 秒** | 含新模型生成、审查、适配修复和各项执行 |
| 文档补充前的已验证包 | 80,721,176 字节 ZIP / 201,153,044 字节解压文件 | 约 **77 MiB / 192 MiB**；加入手册后精确大小可能变化 |

首版未隔离编译中位数为 7.053 秒，旧 worker 中位数为 600.5 ms；这些属于不同策略的历史采样，不作为 v3 的速度。完整测评还包括原始单元检查、探针、夹具编译及 14 次回归，不能以单次编译时间代表总耗时，也不能以本机样本承诺其他电脑的速度。

新版独立便携回放分别复现缺陷 ZIP（67.230 秒）及首位缺陷（52.779 秒），不请求模型。结果页、JSON/CSV 导出及非同源 POST 拒绝（403）已核查。最终包另行解压，核验 1,916 个清单文件；与新在线测评使用的包相比，执行文件与编译/运行依赖相同，后续变化限于验证说明、结果模板及内容相同的标准库 ZIP 元数据。

本地包文件名为 `cpp-assessor-wasm-pilot.zip`，已构建并完成上述验证；**公开下载以 GitHub Releases 的实际附件为准**。如发布 ZIP，应同时提供 `cpp-assessor-wasm-pilot.zip.sha256`，最终大小及校验值以同次发行附件为准。本日志不固定写入旧 ZIP 哈希，避免加入手册、重新打包后误导下载者；此处不预先宣称上传或发布成功。
